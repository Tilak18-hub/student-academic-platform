API Quick Reference

Available routes
GET /health

Check whether the application is running.

Test Health →
GET /api/students/<student_id>

Retrieve a student by ID.

POST /api/students

Create a student using a JSON request body.

POST /api/faculty

Register a faculty member.

POST /api/courses

Create a course and assign its credits and faculty.

POST /api/enrollments

Enroll a student in a course for a semester.

POST /api/grades

Assign a grade for a student’s course enrollment.

GET /api/students/<student_id>/gpa?semester=...

Calculate a student's GPA for a semester.
